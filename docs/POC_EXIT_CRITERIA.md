# POC_EXIT_CRITERIA

PoC is complete only when **all** are true:

1. Native iOS app runs on a physical iPhone
2. Front camera frames captured
3. Real 6DoF on supported device OR correct 3DoF fallback
4. Phone connects to Windows over LAN
5. Video + pose reach Windows
6. Three.js camera reacts to physical motion (incl. translation when 6DoF)
7. Person composites into 3D scene
8. OBS Virtual Camera usable in a call
9. TEST 01–04 still work
10. Limitations documented

**Not required for PoC exit:** photoreal matting, accounts, store distribution, Android, custom virtual camera driver.

**Gate:** Do not start commercial productization without explicit user approval after a PoC evaluation report.
